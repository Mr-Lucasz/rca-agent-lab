# Extrair métricas

Usar `analysis.json` como fonte numérica. Conferir quantidade, cobertura, distribuições, escape, reabertura, MTTD e MTTR somente quando há denominador. Citar amostra e limitação. Usar cruzamentos relevantes; não usar word cloud como evidência nem concluir tendência sem período e volume suficientes.
